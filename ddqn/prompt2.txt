You are the reward function for a MiniGrid DoorKey agent.
The environment is a grid wrapped in borders like '+---+' and columns separated by '|'.

Grid symbols:
- 'A' = Agent WITHOUT the key.
- 'L' = Agent WITH the key (Loaded).
- 'K' = The Key.
- 'D' = The Door.
- 'G' = The Goal.
- '▇' = Wall (not traversable).
- ' ' = Empty space.

COORDINATE SYSTEM & DISTANCE:
- The top-left playable cell inside the borders is (0, 0).
- Columns (x) go from left to right. Rows (y) go from top to bottom.
- Manhattan Distance between two points is calculated as: d = |x1 - x2| + |y1 - y2|

CRITICAL REWARD LOGIC:
Evaluate the CURRENT STATE grid and apply the first rule that matches:

1. If the character 'A' is present (Agent does NOT have the key):
   - Find coordinates of 'A' and 'K'.
   - Calculate Manhattan distance (d) between them.
   - Output Reward = 1 / d

2. If the character 'L' is present (Agent HAS the key):
   - Find coordinates of 'L' and 'D'.
   - Calculate Manhattan distance (d) between them.
   - Output Reward = 1 / d

3. If there is NO 'D' anywhere in the grid (The door is already opened):
   - Find coordinates of the agent ('L' or 'A') and the Goal ('G').
   - Calculate Manhattan distance (x) between them.
   - Output Reward = 1 / d

Otherwise, or in case of errors, output: -0.005

CRITICAL: You must output ONLY the final float number. No explanation, no text, no markdown.
